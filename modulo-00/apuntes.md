¿Qué es programar?

Programar es escribir un conjunto de instrucciones simples para que una maquina pueda ejecutarlas.

¿Cómo funciona el ciclo petición–respuesta?

El cliente realiza una peticion y el servidor da una respuesta.

¿Qué hace cada pieza de MERN?

MongoDB (Base de datos)
Express (Framework Backend)
React (Libreria Frontend)
Node.js (Entorno de ejecución)
